# Gothic II: NK — Cienie Przeszłości

Solucja do modyfikacji **Cienie Przeszłości**, autorstwa VIN-a. Wiki korzysta z Docusaurusa.

## Uruchamianie

Wymagane Node.js 24 i pnpm 11.19.0.

~~~sh
pnpm install --frozen-lockfile
pnpm start
~~~

Podgląd: `http://localhost:3000`. Kontrola: `pnpm check`.

## Edycja

Rozdziały są w `docs/chapters/`, a strona główna w `docs/README.mdx`. Zwykłą treść zapisujemy w `.md`. Zadania mają H2, a zadania i etapy kopaczy pod właściwym zakończeniem — H3. Zachowuj kotwice `{#id}`. Poprawki zgłaszaj przez Pull Request.
